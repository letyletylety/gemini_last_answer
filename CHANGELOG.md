## [2.1.2]

### Fixed

- **GFM Table Conversion**: Fixed table formatting breakage where multi-line elements (`<p>`, `<ul>`, `<li>`, `<br>`) inside table cells split single rows across multiple lines; cell line breaks are now cleanly preserved via `<br>`.
- **Table Pipe Escaping**: Automatically escape internal pipe characters (`|` -> `\|`) inside cells to prevent column corruption.
- **Empty Row Filtering**: Automatically filter out empty spacer rows (`| | | |`) generated by Gemini.
- **Table Heading Fallback**: Added fallback parsing for tables without explicit `<thead>` or `<th>` elements so they convert to Markdown tables rather than raw HTML.

### Added

- **Interactive Test Suite**: Added [test_runner.html](file:///Users/kangtaejin/atelier/gemini_last_answer/test_runner.html) for in-browser visual testing with real-time assertions and a live HTML-to-Markdown playground.
- **CLI Test Suite**: Added [test_table.js](file:///Users/kangtaejin/atelier/gemini_last_answer/test_table.js) for automated GFM table regression testing with Node.js.

## [2.1.0]

### Added

- Support LaTeX math formulas (KaTeX, MathML, MathJax) conversion to `$inline$` and `$$block$$`.
- Support standalone SVG diagram preservation as code blocks.
- Enhanced code block detection for modern Gemini web components (`<code-block>`, `<spark-code-block>`).
- Clipboard fallback mechanism using temporary textarea execution.

### Fixed

- Removed UI button texts (copy buttons, feedback, audio) and UI SVG icons from copied markdown.
- Fixed character escaping issues in LaTeX formulas.
